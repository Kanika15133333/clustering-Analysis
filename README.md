# Clustering Analysis

## Project Overview
This project focuses on exploring and analysing data using clustering techniques.

## Objectives
- Explore and understand the dataset.
- Apply clustering techniques.
- Identify patterns and groups in the data.
- Visualise the clustering results.

## Technologies Used

- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project File
The complete analysis, code and visualisations are available in the Jupyter Notebook included in this repository.
